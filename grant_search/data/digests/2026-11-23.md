Two things changed outside this routine, and one of them needs a decision before

## The working branch was deleted from the remote

`claude/automated-grant-search-zma762` no longer exists on GitHub. It was **not
merged** — 38 commits are absent from `main`, and `grant_search/` is not in
`main` at all.

Meanwhile `main` has moved on independently. It now holds a **Streamlit web
app** — `app.py`, `categories.py`, `requirements.txt`, `phone-preview.png` —
where in August it held five empty placeholder files. The Daily Brain task
organizer that the README described and that did not exist has since been built,
by someone, directly on `main`.

So two possibilities, and they call for opposite responses:

1. **Deliberate.** The grant search was set aside in favour of the app, and the
   branch was deleted on purpose. In that case this routine should stop.
2. **Housekeeping.** Branches were tidied without anyone noticing that one held
   three months of unmerged work.

**This run pushed the branch back up**, because the work existed only in an
ephemeral container that can be reclaimed at any time, and because recreating a
branch is trivially reversible while losing 38 commits is not. If the deletion
was deliberate, deleting it again takes one command and nothing is harmed.

But the routine should not keep running on an assumption either way. **That
decision is yours.**

## The network constraint is diagnosable, and small

A web-fetch capability became available this week, so this run tested whether
funder pages can finally be opened. They cannot — `hfnj.org` and `www.nj.gov`
both fail at **DNS resolution**, because they sit outside this environment's
allowed network domains. Permanent for this session, not transient.

That single constraint shaped the entire project. It cost the SNAP STEPS LOI,
where the 50/50 reimbursement question was never settled. It produced a wrong
HFNJ deadline in August, a three-week error recommending Champions in Action,
and left NJ Preventive Health's eligibility undetermined right up to its
expiry.

**Allowing two hosts would fix it.** `hfnj.org` and `www.nj.gov` cover HFNJ's
guidelines and deadlines plus every county opioid abatement report — which is to
say, both of the two funding streams this project concluded are the best fit. It
needs your approval, and I have not requested it, because it would be a
persistent change to your environment for a project whose status is now unclear.

Say the word and I will ask for it properly.
